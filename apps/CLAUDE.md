# apps/ — router

Um utilitário ou protótipo web pequeno nasce numa pasta própria aqui dentro,
nomeada pelo projeto. Nada aqui ainda — pasta vazia por design (ver `AGENTS.md`).

Quando um app ganha usuários, publicação própria ou ciclo de release, ele vira
repositório próprio na organização (a partir do template do tipo
correspondente, se existir) e some daqui — só a linha no router de topo
(`AGENTS.md`) fica apontando para o novo repositório.
